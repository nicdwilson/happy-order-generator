*** Happy Order Generator Changelog ***

xxxx-xx-xx - version x.x.x
* Add - Enable/Disable setting at the top of the settings page, to pause order generation without deactivating the plugin.
* Add - Warning on admin screens for administrators and shop managers while orders are being generated, showing the hourly rate. It can be dismissed until the next login.
* Add - Generated customers get the "Generated customer (Happy Order Generator)" role, which has no capabilities, and the _happy_order_generator_customer user meta.
* Add - "Requires at least", "Requires PHP" and "Requires Plugins" headers, readme.txt and changelog.txt.
* Add - QIT-equivalent test suite (validation, compatibility, PHPStan, security, audit and Playwright E2E) and GitHub Actions CI.
* Tweak - Order generation only runs on sites whose environment type is local, development or staging. Change the allowed types with the hog_allowed_environment_types filter.
* Tweak - Only customers created by the generator are reused for new orders. Real customers are never used.
* Tweak - Tested up to WordPress 7.1 and WooCommerce 11.3.
* Fix - Products picked at random are now only published products that are in stock or on backorder. Drafts, private products and out-of-stock products could be picked before, and could make the order fail.
* Fix - Fatal error when no supported payment gateway was available for a cart, such as a store with only Cheque enabled. The order is now skipped and logged.
* Fix - Orders containing a subscription now use Stripe when it is available, so they can renew automatically, instead of a random supported gateway.
* Fix - Setting Orders per Hour to 0, leaving it empty or entering a negative number now stops generation, instead of generating about 60 orders an hour.
* Fix - PHP warning when Orders per Hour doesn't divide evenly into an hour.
* Fix - Block checkouts by real shoppers were left pending (HTTP 202) while the plugin was active.
* Fix - The checkout login step now only applies to the generator's own checkout requests.
* Fix - PHP warnings when saving the settings with Enable logging unticked, and when logging on sites that have never saved the settings.
* Fix - Settings save now verifies the nonce and capability, and sanitizes every value.
* Fix - Possible division by zero in the order schedule.

2024-01-10 - version 1.0.1
* Fix - Check that removes non-English locales.

2024-01-10 - version 1.0.0
